# Frog Lily Pad Jumper - Симулятор лягушек

## Описание проекта
Интерактивная симуляция лягушек, прыгающих по кувшинкам через реку. Проект реализован на PyQt5 с расширенной статистикой и управлением.

## 🎯 Основные функции

### Управление симуляцией
- **Регулировка скорости течения** реки (слайдер 20-100)
- **Настройка частоты появления** кувшинок (5-20)
- **Добавление новых лягушек** в реальном времени
- **Пауза/продолжение** симуляции

### Статистика в реальном времени
Для каждой лягушки отслеживается:
- Текущие координаты
- Количество утонувших кувшинок
- Общее пройденное расстояние
- Средняя длина прыжка
- Количество совершенных прыжков

## 🛠 Технические особенности

### Архитектура
- Класс `Frog` для управления состоянием каждой лягушки
- Класс `Window` для отрисовки и управления симуляцией
- Динамическое обновление интерфейса

### Визуализация
- Плавная анимация движения
- Цветовые схемы из JSON-конфигурации
- Отображение следов прыжков
- Реалистичная физика течения реки
